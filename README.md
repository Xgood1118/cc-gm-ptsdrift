# 字幕 PTS 漂移校正

一个能估计并消除音轨与字幕时间基准漂移的对齐器。只用 Python 标准库。

模型约定（字幕时间轴 → 音轨时间轴）：

```
audio_ms = slope * sub_ms + offset_ms
```

- `slope`：漂移率，音轨毫秒 / 字幕毫秒；`slope = 1.0005` 即每 1000 秒慢/快 0.5 秒。
- `offset_ms` / `intercept_ms`：截距，`sub_ms = 0` 时的音轨时间。
- `residual_bound_ms`：所有内点锚点上 `|audio - (slope*sub + offset)|` 的最大值，
  即残差上界；离群锚点不计入。

## 保留签名

- `Cue(index, start_ms, end_ms, text)`
- `load_srt(path)` → `list[Cue]`
- `write_srt(path, cues)`
- `estimate_drift(anchors)` → `dict`（含 `slope`、`offset_ms`、`residual_bound_ms`……）
- `apply_drift(cues, model)` → `list[Cue]`

`anchors` 接受 `[{"sub_ms": ..., "audio_ms": ...}, ...]`，也接受 `(sub_ms, audio_ms)` 序列。

## 估计方法

1. **锚点归一化**：按 `sub_ms` 排序，保证结果与输入顺序无关、可逐字节复现。
2. **RANSAC 式拟合**：用锚点两两连线（锚点超过 `MAX_PAIR_CANDIDATES=4096` 个点对时，
   改为相邻点对 + 固定种子抽样）作为候选直线，以「残差在容差内的锚点数」投票，
   再用内点做最小二乘精修、迭代收敛内点集合。
3. **离群剔除**：落在容差内的即内点；其余为离群锚点，不参与拟合，只在 `dropped`
   与 `outliers` 里如实报告。已剔除的锚点若被重新拟合的直线接受，会重新计入内点。
4. **不粉饰结果**：如果最一致的直线也只覆盖不到半数锚点，说明锚点彼此矛盾，
   退回常量平移，并且残差上界按**全体**锚点计算，避免靠丢弃大多数锚点假装达标。
5. **确定性**：无随机性外泄（抽样用固定种子），浮点运算顺序固定，毫秒换算用
   `floor(x + 0.5)` 而非内置 `round` 的银行家舍入。

## 校正方法

对每条字幕的起点和终点分别做 `slope*t + offset_ms`，再：

- 四舍五入到最近毫秒，**负数一律夹到 0**（SRT 无负时间表示）；
- 单条内 `end < start` 时把 `end` 抬到 `start`；
- 跨条目起点倒序时把当前起点抬到上一条起点（条目密集连播时才会触发）；
- 条目数、序号、文本逐字保留，不原地修改输入。

## 退化路径

- **0 个锚点**：恒等模型（`slope=1, offset=0`）。
- **1 个锚点**：无法确定斜率，`slope` 固定为 1，用该锚点的平移量做常量平移。
- **2 个锚点**：两点必然完美共线，却无法验证「是否线性」、也无法判断谁是离群点，
  因此不采信这条直线，`slope` 固定为 1，截距取两个平移量 `audio-sub` 的中位数。
- **内点不足 3 个 / 拟合震荡不收敛**：无法证实线性，退回常量平移。

以上情况 `degenerate=true`，`reason` 字段给出中文原因。

## 极小漂移不强行校正的判据

设锚点在 `sub_ms` 上的跨度为 `span`，拟合斜率为 `slope`：

```
累计漂移 total = |slope - 1| * span
阈值 MIN_DRIFT_MS = ANCHOR_TOLERANCE_MS / 2 = 40 / 2 = 20 ms
```

**当 `total < 20 ms` 时不套用斜率校正**（`slope_applied=false`，`raw_slope` 仍保留
原始估计值），改为只做常量平移：斜率带来的累计偏差还不到半个容差，强行套用只会把
本来正确的字幕推歪。

阈值取容差的一半，是因为套用斜率后模型相对「真·常量平移」的额外误差不会超过
`total`；`total < 容差/2` 时，不校正的结果仍在容差内，而校正只会引入抖动。

例外：若改用常量平移会把锚点残差推到容差之外（例如锚点跨度很短、离散大），则保留
线性校正，`reason` 会说明原因；这是「避免推歪」而不是「无条件拒绝斜率」。

## 容差

`ANCHOR_TOLERANCE_MS = 40.0` 毫秒。同一把尺子同时用于：

- 判定锚点是否为内点；
- 校正结果是否合格——真值模型下每条字幕起止时间与期望值的偏差都不超过 40 ms。

可用 `--tolerance-ms` 在命令行覆盖。

## 自测

```
python -m pytest tests -q
python -m ptsdrift.cli data/sub.srt --anchors data/anchors.json --out fixed.srt
```

测试覆盖：离群锚点剔除、残差上界（含噪声超容差时如实报大）、负时间不出现、条目内
不倒序、跨条目不倒序、退化路径（0/1/2 个锚点、同 x、全离群）、极小漂移不校正、
正文与序号不变、源文件不被改写、两次运行逐字节一致（含不同 `PYTHONHASHSEED`）。
